Project Boundaries

Project Scope

Security Audit Project / Scope Definition

INCLUDED (In Scope)

Vulnerability Scanning

Automated scanning of web applications & network infrastructure for common flaws.

Port & Service Enumeration

Identifying open ports, running services, and version information.

Basic Penetration Testing

Controlled manual testing to validate critical vulnerabilities like SQLi & XSS.

Automated Reporting

Generation of structured PDF audit reports with severity scores.

EXCLUDED (Out of Scope)

Strictly Prohibited Activities

Live Destructive Attacks (DoS/DDoS)

Attacks that compromise availability or crash the target system are strictly forbidden to ensure business continuity.

Advanced Privilege Escalation

Lateral movement and deep system exploitation beyond the initial vulnerability confirmation are not included.

Social Engineering (Phishing)

Human-centric attacks such as phishing emails or pretexting calls are outside the technical scope of this audit.
