While the security audit framework is robust, certain inherent limitations exist due to the scope, methodology, and ethical considerations of the project.

Project Boundaries

01

Automated Focus

The system relies on automated scanners. Complex business logic errors (e.g., payment bypass flows) cannot be detected without manual human intuition.

Logic Gaps
02

Non-Intrusive

Strictly ethical boundaries meant no Denial of Service (DoS) or aggressive brute-force attacks were performed, potentially leaving stress-related bugs unfound.

Ethical Safety
03

Snapshot Validity

Security is valid only for the specific moment of the scan. Subsequent code updates or newly discovered CVEs may introduce new risks immediately after.
