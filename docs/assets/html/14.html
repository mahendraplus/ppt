Database Schema

Data Dictionary

SPCE / MCA / SEM-IV

Core entity definitions for the MySQL database handling audit data, user sessions, and reporting.

User Table
Field Name Data Type Description
PKUserID INT(11) Unique identifier. Auto-increment.
Username VARCHAR(50) Unique login name.
PasswordHash VARCHAR(255) Bcrypt hashed password.
Role ENUM 'Admin', 'Auditor', 'Viewer'.
Scan Table
Field Name Data Type Description
PKScanID INT(11) Unique ID for each scan session.
Target VARCHAR(255) Target IP or Domain URL.
ScanType VARCHAR(50) 'Quick', 'Full', 'Custom'.
Status VARCHAR(20) 'Running', 'Completed', 'Failed'.
Vulnerability Table
Field Name Data Type Description
PKVulnID INT(11) Unique ID for a specific finding.
FKScanID INT(11) Links to parent Scan record.
Name VARCHAR(150) Title (e.g., 'SQL Injection').
Severity VARCHAR(10) 'High', 'Medium', 'Low'.
Report Table
Field Name Data Type Description
PKReportID INT(11) Unique report identifier.
FKScanID INT(11) Links to source Scan.
FilePath TEXT Relative path to PDF file.
GenDate DATETIME Timestamp of report creation.
