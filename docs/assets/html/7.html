Project Boundaries

Project Scope

SPCE / MCA / SEM-IV

INCLUDED (In Scope)

Vulnerability Scanning

Automated scanning of web applications & network infrastructure for common flaws.

Port & Service Enumeration

Identifying open ports, running services, and specific version information.

Basic Penetration Testing

Controlled manual validation of critical vulnerabilities like SQL Injection & XSS.

Automated Reporting

Generation of structured PDF audit reports with standardized severity scoring.

EXCLUDED

Out of Scope

Destructive Attacks (DoS)

Attacks that compromise availability or crash the target system are strictly forbidden.

Advanced Privilege Escalation

Lateral movement and deep system exploitation beyond initial confirmation.

Social Engineering

Human-centric attacks (phishing, pretexting) are outside technical scope.
